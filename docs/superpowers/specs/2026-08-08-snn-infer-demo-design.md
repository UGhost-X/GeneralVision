## 六步公式（与 snn.py 逐行一致）

| 步 | 公式 |
|---|---|
| ① 输入像素 | `px[i] = u[i]/255` ∈ [0,1]，784 维 |
| ② 速率编码 | `P[i] = px[i] × spike_gain`（0.6）；每步 `spike[i] ~ Bernoulli(P[i])`，共 T=200 步 |
| ③ LIF 积分 | `V[j] = V[j]×leak + Σᵢ W[i,j]·spike[i]`（leak=0.94）；不应期跳过；WTA：V≥θ 中取最大者放电，winner V→0 且 refr=4，其余非不应期 refr=1 |
| ④ 放电计数 | `spikeAccum[j]++` 每次放电；累计到 T=200 |
| ⑤ 标签读出 | `pref[j]=argmax_d digCount[j,d]`（训练时统计）；`c[d] = Σ_{j:pref[j]=d} spikeAccum[j]` |
| ⑥ 分类概率 | `P(d) = c[d]/Σ`；预测 = argmax |

## 各步展示的真实数值

| 步 | 展示内容 | 数据来源 |
|---|---|---|
| ① | 最亮像素 `px`、亮像素（px>0.5）个数 | `cur.px` |
| ② | 某像素 `P` 值、该像素实际放电 `n/200` 次 | 编码器累计 |
| ③ | 最近放电神经元 `#j` 在 `t` 步 `V≥θ` 放电；V 迷你波形（积分→过阈→归零） | fire 事件快照 + V 历史 |
| ④ | 最近放电神经元 `#j` 累计 `n` 次；全体总放电 `m` 次 | `spikeAccum` |
| ⑤ | 各数字分组计数 `c_0..c_9` | 按 pref 分组求和 |
| ⑥ | `P(0)..P(9)`，argmax 高亮，最终判定文本 | 归一化 |

## 动画与交互

- **控制**：数字选择 / 随机 / 播放暂停 / 速度（步/帧倍率）/ 重置。
- **顶部动画行**：输入图高亮当前编码的像素；100 神经元脉冲柱随 t 跳动（放电闪光）；概率柱随累计数实时增长。
- **迷你 V 波形**：最近放电神经元的膜电位轨迹（160×36），展示「积分升高→过阈→放电→归零」。
- **重置**：V/refr/累计/波形/概率全部清零，可重新播放。

## 边界情况

- **未放电（概率分母为 0）**：⑥ 显示占位「本图无神经元放电」，不除零。
- **推理播放结束**：顶部判定文本 + 概率柱最终态；再次播放重置计数。
- **窄窗口（<900px）**：顶部动画行与六步面板缩放不溢出，无水平滚动。

## 实现要点

- **JS 前向**：`_poisson`（伯努利采样，`rand < P`）、`step()`（`V+=Wᵀ·spike` → 不应期清零 → `×leak` → WTA → fire → refr 递减）逐帧实现，与 `snn.py` 一致。
- **权重导出**：`export_snn_demo.py` 训练后以 Float32 顺序写入 base64；JS 用 `atob` + `DataView` 还原 `Float32Array`。
- **参数**：优先用项目基线（`w_norm=16, theta_init=25, theta_clamp=(5,100), a_plus=0.8, leak=0.94, refr=4, spike_gain=0.6, T=200`）。导出后实测 group-by-pref 准确率，若不佳再调参（如经典 78.4/15）。
- **训练样本量**：导出脚本默认 2000 张，训练后 `calibrate` 补 dig_count，保证每神经元偏好稳定。

## 验证方式

1. 运行 `export_snn_demo.py`：训练完成、打印 group-by-pref 验证准确率、生成 `snn_weights.js`。
2. 浏览器打开 `snn_demo.html`：抽查若干数字，六步面板数值与 Python 真实输出对得上。
3. 播放动画流畅、概率柱与最终判定一致；随机多次无 NaN。
4. 窄窗口（<900px）无水平滚动。
5. STDP 文字说明公式与代码常量一致。
