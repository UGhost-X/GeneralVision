# LIF 生态游戏：个体在线学习能力设计文档

日期：2026-08-09
状态：已批准，进入实施
范围：eco_engine.py / eco_server.py / eco_game.html

## 1. 背景与动机

当前生态游戏中，生物体的一切能力都由基因决定：隐藏层是**冻结的随机水库**，只有读出层在体检期被全局岭回归重拟合（批次式、每 5 回合一次、只对 top 个体）。个体在生命周期内**没有任何自身的权重更新**——能力完全依赖遗传，这不符合"像简单生物大脑一样在线更新局部权重"的设想。

目标：给个体添加真正的**生命周期内学习能力**，让进化作用于"先天起点 + 学习能力"（Baldwin 效应），而非直接编码最终表现。

### 已确认的关键决策

| 维度 | 决定 | 说明 |
|---|---|---|
| 学习范围 | 读出层 + 隐藏层都学 | 隐藏层用三因子奖励调制 |
| 遗传边界 | 韦斯曼式 | 基因型(先天)与表型(学习后)分离 |
| 隐藏层规则 | 三因子奖励调制 | 局部 Hebbian 资格迹 × 全局对错奖励 |
| 教学信号 | 监督式 | 喂食后广播标签；食物即学习流 |
| 学习时机 | 成熟期 + 在线 | 出生发育期 + 每回合在线微调 |
| 落地策略 | 方案 A 分层落地 | P1 骨架 → P2 隐藏层 → P3 体检与前端 |

## 2. 架构：基因型 / 表型分离（P1 核心）

```
Genome（基因型 = 先天，可遗传、可突变）
 ├─ layer_sizes, weights        # 先天权重（出生起点）
 └─ LearningGenes（新增，可遗传可变异）
     ├─ readout_lr              # 读出层 delta 学习率 (0.0–1.0, 起点 ~0.2)
     ├─ hidden_plasticity       # 隐藏层三因子强度 (0.0–1.0, 起点 ~0.05)
     └─ plasticity_drift        # 表型向基因型漂移率 (0.0–0.5, 起点 ~0.0)

Organism（表型 = 后天，当前能力）
 ├─ genome: Genome              # 基因型，遗传与变异只碰这里
 └─ learned_weights: ndarray    # 当前学习后权重，出生 = genome.weights.copy()
     ├─ 死亡时置 None 释放内存
     └─ 前向 / 体检 / 喂食全部用 learned_weights
```

语义要点：

- **前向管道零改动**：`forward()` 仍收 `Genome`，用轻量 shim 让 `.weights` 指向表型数组（不拷贝）。`_pack_batch`/`_stack_genome_group` 本就按个体复制权重，天然兼容。
- **交叉 / 变异只碰基因型**：`crossover`、`_mutate_genome` 读 `genome.weights`（先天），学习永不污染基因 → 韦斯曼屏障成立。
- **`_fit_readouts` 语义改变**：当前把岭回归写进 `genome.weights`（隐性拉马克）。改为——奠基筛选仍写基因型（bootstrap 初始种群），体检期改为写**表型**（见 §5 睡眠巩固）。
- 内存代价：每个存活个体多一份表型副本（典型 0.3–0.8MB），死亡即释放。Founder 缓存只存基因型，不放大。

## 3. 学习规则

### 3.1 读出层：监督 delta rule（局部、在线、批量）

每回合喂食后，对所有存活个体：

```
err = softmax(logits) − onehot(label)
ΔW_out = −readout_lr · outer(hidden_rate, err)
Δb_out = −readout_lr · err
```

每个输出神经元只用**自己的输入活动 + 自己的误差** → 严格局部。einsum 批量计算，开销可忽略。

### 3.2 隐藏层：三因子奖励调制（速率协方差资格迹）

前向 T 窗口内顺带累积每层 `pre_accum`、`post_accum`（各神经元发放计数），然后：

```
E_ij  = pre_accum_i · post_accum_j          # 速率协方差 = 局部 Hebbian 资格迹
δ     = R − R̄                               # 奖励预测误差，R=+1 对 / −1 错，R̄ 为个体平滑基线
ΔW_h  = hidden_plasticity · δ · E            # 三因子：局部资格迹 × 全局神经调质
```

取舍说明（写入文档的诚实声明）：用**速率协方差**而非逐时间步 spike-timing 迹，因为后者对每个体每条突触做 T 次外积，批量下算不起；速率形式仍保留"局部 × 全局"的三因子本质，代价是丢失脉冲时序相关性。

### 3.3 稳定性（三因子的命门）

- **漂移回基因型**：每回合学习后 `phenotype ← genotype + (phenotype−genotype)·(1−plasticity_drift)`。模拟遗忘/巩固，锁死学习偏离先天的上界，让遗传继续有意义。漂移率是学习基因，进化可调。
- **突触缩放**：对每个隐藏神经元，将入向权重范数软钳制到目标。WTA 赢家自带稀疏性，防跑飞。
- **隐藏层学习频率**：可配置 `hidden_learn_every`（默认每回合，可降频省算力/降噪声）。

### 3.4 成熟期（出生时）

新生儿出生即跑一段发育：抽 `MATURITY_SAMPLES`（默认 6）张**训练集**图，逐张走前向 + 读出 delta + 隐藏三因子，初始化表型。用训练集而非食物流 → 保证评测诚实。成本 ≈ 6 × 新生儿数 的前向，可批量，可开关。

## 4. 生命周期改造（P1/P2）

现有 `step()`：喂食 → 产出 → 淘汰 → 繁殖 → 体检。改造后插入学习阶段：

```
喂食（抽数字，监督标签）
  → 表型前向，判定对错
  → 【在线学习】全存活个体：
       ① 读出层 delta rule（标签 + 隐藏率）
       ② 隐藏层三因子（对错奖励 × 资格迹）
       ③ 表型向基因型漂移（稳态）
  → 衰老/自然死亡、配对、繁殖
  → 【新生儿成熟期】：表型=基因型副本，抽 K 张训练集图
      批量前向 + 读出delta + 隐藏三因子，初始化表型
  → 每 5 回合体检（表型评估 + 睡眠巩固）
```

### 4.1 前向要"吐学习原料"

新增 `forward_learn()`（或 forward 加可选 flag）：在 `_forward_group_vectorized` / `_forward_core_multi` 中顺带返回每层 pre/post 活动累积（资格迹）与最后一层隐藏率。numba 回退路径在 per-organism 循环里天然好加。

### 4.2 体检语义变化

- **评估用表型**：`_score_digits`/`_confidence_digits`/fitness 全部走学习后权重 → 进化选择的是"先天起点 + 学习能力"（Baldwin 效应可见）。
- **`_fit_readouts` 改为写表型**（睡眠巩固）：体检时用训练集岭回归重拟合表型读出层。强批量学习与弱在线学习互补，都不污染基因。

### 4.3 反馈闭环

学习量（`||learned − innate||`）作为可观测指标进前端 → 可直接看到"这只个体学了多少、基因给了多少起点"。

## 5. 性能预算

现状 0.56s/回合（1000 个体）。预估改造后：

| 开销项 | 增量 |
|---|---|
| 读出 delta + 漂移 + 突触缩放 | ≈0（einsum 级） |
| 隐藏三因子资格迹累积 | +20–40%（典型 1 层 100 神经元，outer(784×100) 批量） |
| 成熟期 | K×新生儿前向，K=6、可开关 |

预估 **0.9–1.3s/回合**。三个省钱旋钮：`hidden_learn_every`（降频）、`maturity_samples`（0=关）、学习总开关。

## 6. 前端（eco_game.html）

- 解剖面板新增：**学习量**（|learned−innate|/|innate|）、三项学习基因、已学习样本数、每层权重变化热条。
- 曲线：学习量均值曲线、隐藏可塑性基因进化轨迹。
- 滑块：成熟期样本数、隐藏学习频率、学习总开关。

## 7. 诚实验证计划（固定 seed 对照组）

| 组 | 内容 | 度量 |
|---|---|---|
| R0 | 纯遗传（学习关，= 现状） | accuracy 轨迹 |
| R1 | P1：成熟期 + 读出 delta | 同上 + 学习增益 |
| R2 | R1 + 隐藏层三因子 | 同上 + 隐藏可塑性基因演化值 |

关键诚实点：**若三因子无效或有害，如实报告**——这正是它区别于"伪学习"的证据。学习增益（成熟前后、喂食前后）单独度量，防止把遗传优势误当学习成果。

## 8. 落地阶段（方案 A）

- **P1 学习骨架**：基因型/表型分离 + 成熟期读出层 delta 学习 + 学习基因。验证 R0 vs R1。
- **P2 隐藏层三因子**：速率协方差资格迹 × 对错奖励 + 漂移/突触缩放稳态。验证 R1 vs R2。
- **P3 体检与前端**：表型评估 + 睡眠巩固重拟合 + 前端展示。最终诚实报告。

## 9. 明确不做（YAGNI）

- 不做 spike-timing 精确 STDP（算力不可行）。
- 不做逐层反向传播 / surrogate gradient（违反"局部权重"原则）。
- 不做拉马克式遗传（违反韦斯曼决策）。
- 不做跨代记忆 / 文化传承。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 三因子隐藏学习无效或有害 | 隐藏可塑性为可遗传基因，进化自选强度；R1/R2 对照诚实报告 |
| 隐藏学习失稳（跑飞） | 漂移回基因型 + 突触缩放双保险 |
| 表型内存翻倍 | 死亡即释放；典型个体 0.3MB 级 |
| 每回合变慢 | hidden_learn_every / maturity_samples / 总开关三旋钮 |
| 学习污染基因（隐性拉马克） | 交叉/变异只读基因型，学习只写表型 |
