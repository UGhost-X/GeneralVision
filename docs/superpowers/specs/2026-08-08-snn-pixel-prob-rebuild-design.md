## 背景

`snn_demo.html` 是一张 LIF + 胜者全取 + STDP 的单层脉冲网络教学演示页。当前页面包含：4 阶段 pipeline（输入→编码→LIF→输出）、栅格图、膜电位示波器、权重网格学习面板、静态 6 节点 SVG 计算流程图（`8081f4b` 引入）。

用户反馈（本轮）：

> 现在这个整理的太复杂了，这个工作流（4 阶段 pipeline + 静态流程图）的可视化不是我需要的，全部移除。我需要的是「像素 → 概率：这张图是怎么算出来的」这个部分：**具体计算公式推理** 以及 **参数更新的可视化**。

已与用户确认的四点：
1. **范围**：整页精简重做（去掉工作流式可视化）。
2. **形态**：保留实时仿真动画（播放/学习/推理），作为两块新面板的活数据源。
3. **计算演算**：实时演算面板——仿真播放时，6 步公式用当前图的**真实数值**逐行展开。
4. **参数更新**：实时 ΔW 高亮——学习时权重网格高亮被更新的突触并读出 ΔW 数值。

## 非目标

- 不改 `simStep()` / `fire()` / `resetWeights()` 的数值算法（只加数据埋点，不改计算）。
- 不做概率/时序层面的准确率改进（教学演示，不追求分类精度）。
- 不新增依赖、不拆分文件、保持单文件自含。

## ① 实时演算面板（`.calc-panel`）

纵向 6 行，每行格式：`步骤号（琥珀）| 公式（mono 绿）| 当前图真实数值（mono，青色数值）`。
播放时逐行实时刷新；样本放完，⑥ 显示该图最终概率。

| 步骤 | 公式（对应代码常量） | 显示的真实数值 | 数据来源 |
|---|---|---|---|
| ① 输入像素 | `px[i] ∈ [0,1]`，784 维 | 最亮像素 `px=0.85`；亮像素数（px>0.5） | `cur.px` |
| ② 速率编码 | `P = px × 0.6`（`SPIKE_GAIN=0.6`） | 最亮像素 `P=0.51`；该像素本图实际放电 `n/200` 次 | 新增 `preCount[i]` 埋点 |
| ③ 积分放电 | `V ← LEAK·V + Σ W·spike`（`LEAK=0.94`）；`V ≥ θ` 放电 | 最近一次放电的神经元 `#j` 在 `t` 步 `V=15.3 ≥ θ=15.0` 放电（跟随 `lastFire`） | fire 时刻快照：`fireT`/`fireV`/`fireTheta`（`simStep` 调 `fire(winner)` 前记录 `bestV` 与 `theta[winner]`） |
| ④ 放电计数 | `spikeAccum[j]++`，`T=200` | 最近放电的 `#j` 本图累计 `n` 次；全体总放电 `m` 次 | `spikeAccum`（跟随 `lastFire`） |
| ⑤ 按数字分组 | `c_d = Σ_{pref[j]=d} spikeAccum[j]` | 各数字计数 `c_0..c_9` | `computeProb()` 中间量 |
| ⑥ 概率分布 | `P(d) = c_d / Σ` | `P(0)..P(9)`，argmax 高亮 | `computeProb()` |

### 新增数据埋点（不改数值算法）
```js
let preCount = new Float32Array(NIN);        // 每个输入像素本图累计放电次数
// simStep() 内：像素 i 放电时 preCount[i]++
// startSample() 内：preCount.fill(0)
```
其余全部读取现有状态（`cur.px`、`V`、`theta`、`spikeAccum`、`pref`、`vAll`、`thAll`）。

### ③ 行内可选微型图
③ 行右侧可附一段胜者神经元的迷你膜电位 sparkline（复用 `vAll/thAll`，约 160×36），展示「V 积分升高 → 越过阈值放电 → 归零」。属于增强项，实施时若挤占布局可省略。

## ② 参数更新面板（`.dw-panel`）

- 权重网格沿用 `renderGrid()`（10×10 神经元，每神经元 28×28 权重块按 `DCOL[pref]` 着色）。
- **学习模式**下，神经元 `j` 放电执行 STDP 时：
  - **ΔW 高亮**：本次被更新的突触（`W[i*N+j] += A_PLUS` 的 `i`，即最近 `TAU_PLUS` 步内放过电的输入像素）在网格对应像素格**闪白高亮**，逐帧衰减（`flash` 数组）。视觉呈现为「数字形状被描亮」，直观展示权重朝数字形状生长。
  - **ΔW 读出**（网格下方一行）：`神经元 #j（偏好 d）：n 个突触 +0.8，归一化 ×c`
    - `n` = 本次执行 LTP 的输入突触个数（`fire()` 内统计）
    - `+0.8` = `A_PLUS = 0.8`
    - `c = W_NORM / s`（`W_NORM=78.4`，`s` 为归一化前的列权重和）
- **推理模式**：网格静态显示已学权重（与现一致），不做闪烁、不显示 ΔW 读出。

### 新增数据
```js
let flash = new Float32Array(NIN * N);       // ΔW 高亮强度，fire() 置 1，逐帧 ×0.85 衰减
// renderGrid() 内：在权重块上叠加 flash 白亮
// fire() 内：本次 LTP 的 (i, j) 置 flash[i*N+j] = 1；统计 n；记录 c
```

## ③ 交互与边界情况

- 模式切换 / 播放 / 重置逻辑不变（`mode`、`startRunning()`、`frame()`、`onSampleDone()` 沿用）。
- **未学习（`trained === 0`）**：
  - ①②③④ 照常算（随机权重也能积分，数值真实）。
  - ⑤⑥ 显示提示「先切到「学习」播放一轮，才有神经元偏好分组」。
- **学习模式**：
  - ①②③④ 照常实时刷新。
  - ⑤⑥ 显示「学习模式下不判定概率」（沿用现有「学习中」逻辑）。
- **全程无放电（概率分母为 0）**：⑥ 显示占位「本图无神经元放电」，不除以零。
- ③ 步若无神经元放电过，显示「尚无神经元放电」。

## ④ 验证方式

1. 浏览器打开 `snn_demo.html`：4 阶段卡片 / 栅格图 / 示波器 / 静态流程图消失；新两块面板出现；深色主题一致；无水平滚动。
2. 切「学习」播放一轮（`trained` 到 400）后切「推理」：输入任意数字播放，演算面板 ①②③④ 数值随图实时变化；放完 ⑥ 概率柱与「数字 X」判定一致。
3. 学习播放中：网格上被更新突触闪白，ΔW 读出数值与代码常量一致（`+0.8`、`×c` 与 `W_NORM/s` 相符）。
4. 重置：权重归零，演算面板与闪烁全部清零，`trained=0` 提示恢复。
5. 常量核对：面板公式与 `SPIKE_GAIN=0.6`、`LEAK=0.94`、`T=200`、`A_PLUS=0.8`、`W_NORM=78.4` 一致。
6. 窄窗口（<900px）：两块面板缩放不溢出。
