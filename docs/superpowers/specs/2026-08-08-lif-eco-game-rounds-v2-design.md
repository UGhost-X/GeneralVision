# LIF 生态游戏 v2 — 回合制重构设计

> 在已交付的 v1（天制、固定 60 种群、按吃对率加权繁殖）基础上的**行为重构**。v1 代码（`eco_engine.py`/`eco_server.py`/`eco_game.html`）作为基础改造，不改文件结构。

## 背景

用户对 v1 提出三组改动，经过多轮澄清后整合为以下回合制生态模型。核心转变：**"天"→"回合"、种群由"固定 60"改为"可增长但有承载力"、繁殖由"按吃对率加权选亲本"改为"存活者随机两两配对 + 存活时长加权交叉"、死亡区分自然/非自然**。

## 回合循环（一个回合）

```
抽 1 个食物数字 → 全部存活者各吃 1 次、各产出 1 个 → 判定死亡 → 存活者随机两两繁殖 → 密度依赖 → 下一回合
```

1. **喂食**：每回合随机抽 1 个数字（0-9）作为食物，全部存活者各吃一次、各产出 1 个数字。
2. **非自然死亡**：产出 ≠ 食物 → 当回合死亡（**不计入停止指标**）。
3. **自然死亡**：活到**存活回合数**上限 → 自然死亡（**计入停止指标**）。繁殖不额外减寿（用户已移除"繁殖后 3 回合必死"）。
4. **随机两两繁殖**：存活者打乱顺序两两配对，每对产 **存活回合数 × N** 个后代。
   - 每个后代 = **存活时长加权交叉**：单个权重取双亲中某一方的概率 = 该方存活回合数 / (双亲存活回合数之和)；存活相同即 50/50。
   - 交叉后叠加小扰动（σ=0.01）+ 极小概率大突变（0.1%），列归一化——复用现有 `crossover`，仅把 50/50 掩码改为加权。
5. **密度依赖（承载力）**：产仔数 × max(0, 1 − 当前种群/承载力)；并以 `min(总产仔, 承载力 − 存活者数)` 硬上限，保证种群 ≤ 承载力。
6. **全灭重播**：某回合后种群为空 → 重新播种初始种群（事件标记 reseed）。

## 停止条件

累计**自然死亡 / 累计总死亡 ≥ 95%** 即停止（即 95% 生物能活到存活回合数上限）。每回合因为生产错误的死亡为非自然死亡、不计入。

## 可调参数（前端可改，经 /api/config 下发引擎）

| 参数 | 范围 | 默认 | 说明 |
|---|---|---|---|
| 投喂速度 | 1-10 秒/回合 | 5 | 前端回合动画时长（纯显示，服务端计算即时完成） |
| 存活回合数 | 10-30 | 20 | 自然寿命上限（回合） |
| N | 10-100 | 50 | 每对每次繁殖数量 = 存活回合数 × N |
| 承载力 | 100-5000 | 1000 | 种群上限（密度依赖约束） |
| 初始种群 | 60-1000 | 60 | 第 0 回合 / 全灭重播时的播种数 |

## 事件 schema（服务端 → 前端）

- `round_begin {type, round, food_label}`（每回合 1 个食物）
- `org_round {type, name, produced, correct, age}`（每只存活者产出）
- `death {type, name, cause}`（cause = natural | unnatural）
- `birth {type, name, parents:[2], gen}`
- `reseed {type, count}`（全灭重播）
- `round_end {type, stats}`，stats = `{round, alive, avg_acc, natural_deaths, total_deaths, natural_rate}`

`/api/state` 额外返回配置（survival_rounds/N/capacity/initial_pop）与 natural_rate；`/api/config`（POST）更新可调参数。

## 前端改动

- "第 N 天" → "第 N 回合"；速度滑条改为 1-10 秒/回合。
- **只展示当前存活种群**，死亡个体从网格立即移除（不留灰色块）。
- 培养皿网格改用 **canvas 绘制**（种群可到承载力上限，DOM 卡片不现实）：每只存活者一个色块，色块颜色反映本回合产出对错/存活时长；点击色块看解剖。
- 新增调节：存活回合数（10-30）、N（10-100）、承载力（100-5000）、初始种群（60-1000）→ 调 `/api/config`。
- 停止条件指示：natural_rate 实时进度条（目标 95%），达成时提示。
- 保留：手动喂食（喂一个数字给指定/随机个体）、个体解剖（产出神经元脉冲分布）、统计曲线（正确率/种群数/natural_rate）。

## 诚实预期（必须如实呈现）

随机权重下"喂 1 个、错者死"→ 每回合约 90% 非自然死亡；自然死亡需个体**连续 N 个回合全对**才发生，随机权重下几乎不可能 → **"自然死亡 95%"停止条件基本不可达**，游戏会持续运行、种群在承载力附近波动，直到用户手动停止或参数调得极有利。这是机制必然结果，忠实实现、如实报告。

## 与 v1 的关系

v1 的 STDP 进化系统（`evolve.py`）不受影响。v1 生态游戏代码被本设计改造（回合制）。设计/实施文档独立记录。
